## World Destruction

### Block Damage System
| Tool | Block Types | Speed | Notes |
|---|---|---|---|
| Bare hands | Dirt, sand | Very slow | Last resort |
| Shovel | Dirt, sand, gravel | Fast | Intended for soft blocks |
| Pickaxe | Stone, ore, concrete | Medium | Mining tool |
| Axe | Wood, planks | Medium | Tree felling |
| Sledgehammer | Any | Medium | Universal breaker |
| Explosives | Any | Instant (radius) | Expensive, loud |
| Vehicles | Fences, thin walls | On impact | Crash damage |

### Destruction Rules
- Every voxel in the world is destructible (no indestructible blocks)
- Different materials have different HP (dirt < wood < stone < metal < reinforced)
- Destroyed blocks drop resources (stone drops stone, wood drops planks)
- Terrain regeneration: OFF by default, optional server setting
- Blast radius: explosives destroy blocks in a sphere
- Structural integrity: unsupported blocks fall (gravity for non-terrain)
- Fire spread: wooden structures catch fire, spread to neighbors

## Day/Night Cycle

| Time | Light Level | Gameplay Effect |
|---|---|---|
| Dawn (05:00-07:00) | Rising | Animals wake, infected less aggressive |
| Morning (07:00-12:00) | Full | Safe-ish travel, clear visibility |
| Afternoon (12:00-17:00) | Full | Peak activity |
| Dusk (17:00-19:00) | Fading | Prepare shelter, light sources |
| Night (19:00-05:00) | DARK | NVGs essential, predators active, infected aggressive |

- Full cycle: configurable per server (1 hour real = 1 day default)
- Moon phases affect night brightness
- Overcast reduces daytime light
- Indoor areas always dark without light sources

| Kick player | Remove from server |
| Ban player | Permanent removal |
| Teleport | Move to coordinates or player |
| Spawn item | Place any item |
| Set time | Change day/night |
| Set weather | Force rain/fog/clear |
| God mode | Invincibility |
| Invisible | Other players can't see you |
| Restart server | Scheduled or immediate |
| Whitelist | Allow-list only |
| Server message | Broadcast to all players |

### Server Configuration
- Password protection (optional)
- WebAuthn admin keys (YubiKey-backed server ownership, same as ILGPU.P2P)
- Max players
- Loot multiplier
- Day/night speed
- Zombie/animal toggle + density
- PvP on/off zones
- Base damage on/off schedule (raid hours)
- Difficulty presets

### P2P Server Architecture
- All via SpawnDev.WebTorrent
- BEP46 for mutable server listings (publish server info to DHT)
- Tracker-based discovery (find servers on `hub.spawndev.com`)
- WebRTC data channels for game traffic
- Server browser with ping, player count, settings display
- No centralized servers required (but official servers can exist)
